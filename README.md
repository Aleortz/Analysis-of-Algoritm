# Analysis of Algorithms

This repository contains implementations, class notes, and problem solutions for the **Analysis of Algorithms** course at **Yachay Tech University**.

## 📚 Repository Structure

- **`Implementations/`** - Algorithm implementations with detailed explanations
- **`ClassNotes/`** - Course materials, lecture notes, and theoretical concepts
- **`ProblemSolutions/`** - Solutions to algorithmic problems and exercises

## 📖 About

This repository serves as a comprehensive resource for studying algorithm analysis, covering:

- Time and space complexity analysis
- Algorithm design techniques (divide and conquer, dynamic programming, greedy algorithms, etc.)
- Data structures and their implementations
- Classic algorithms and optimizations
- Problem-solving strategies

## 🚀 Getting Started

### Prerequisites

- Python 3.x (for Python implementations)
- Git for version control

### Cloning the Repository

```bash
git clone https://github.com/Aleortz/Analysis-of-Algoritm.git
cd Analysis-of-Algoritm
```

### Navigating the Repository

1. Browse `Implementations/` for algorithm code
2. Check `ClassNotes/` for theoretical concepts and notes
3. Explore `ProblemSolutions/` for solved problems
