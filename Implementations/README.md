# Algorithm Implementations

This directory contains implementations of various algorithms studied in the Analysis of Algorithms course.

## Organization

Implementations are organized by category:

- **Sorting Algorithms** - Various sorting techniques and their analysis
- **Searching Algorithms** - Binary search, linear search, and variations
- **Graph Algorithms** - BFS, DFS, shortest path, minimum spanning tree
- **Dynamic Programming** - Classic DP problems and solutions
- **Greedy Algorithms** - Greedy approach implementations
- **Divide and Conquer** - Problems solved using divide and conquer strategy

## Format

Each implementation includes:

1. **Code** - Well-commented implementation
2. **Complexity Analysis** - Time and space complexity
3. **Usage Examples** - How to use the implementation
4. **Test Cases** - Sample inputs and outputs

## Contributing

When adding new implementations:

- Use clear, descriptive variable names
- Add comprehensive comments
- Include complexity analysis
- Provide test cases
