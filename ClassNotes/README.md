# Class Notes

This directory contains lecture notes, theoretical concepts, and study materials for the Analysis of Algorithms course.

## Organization

Notes are organized by topic:

- **Asymptotic Notation** - Big O, Omega, Theta notations
- **Recurrence Relations** - Solving recurrences, Master theorem
- **Sorting and Searching** - Analysis of various algorithms
- **Data Structures** - Trees, graphs, heaps, hash tables
- **Algorithm Design Techniques** - DP, greedy, divide and conquer
- **Graph Algorithms** - Traversal, shortest paths, MST
- **Complexity Classes** - P, NP, NP-Complete problems

## Format

Notes may include:

- Markdown documents with explanations
- Mathematical formulas and proofs
- Diagrams and illustrations
- Code snippets for demonstration
- Practice problems

## Using the Notes

- Notes are written in Markdown for easy reading
- Each topic includes theoretical background
- Examples are provided to illustrate concepts
- References to implementations and problem solutions
