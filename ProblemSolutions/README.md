# Problem Solutions

This directory contains solutions to algorithmic problems and exercises from the Analysis of Algorithms course.

## Organization

Solutions are organized by:

- **Problem Source** - Textbook, assignments, competitive programming
- **Topic** - Algorithm category or technique used
- **Difficulty** - Easy, medium, hard

## Format

Each solution includes:

1. **Problem Statement** - Clear description of the problem
2. **Approach** - Strategy and algorithm used
3. **Implementation** - Complete, working code
4. **Complexity Analysis** - Time and space complexity
5. **Test Cases** - Input/output examples

## Problem Categories

- **Array and String Problems**
- **Dynamic Programming**
- **Graph Problems**
- **Greedy Algorithms**
- **Tree and BST**
- **Backtracking**
- **Divide and Conquer**

## Contributing

When adding solutions:

- Include complete problem statement
- Explain your approach clearly
- Provide clean, readable code
- Analyze complexity
- Include test cases
